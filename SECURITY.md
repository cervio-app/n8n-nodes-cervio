# Security Policy

## Supported versions

Only the latest published version of [`@cervio/n8n-nodes-cervio`](https://www.npmjs.com/package/@cervio/n8n-nodes-cervio) receives security fixes.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security reports.

Prefer one of:

1. [GitHub Security Advisories](https://github.com/cervio-app/n8n-nodes-cervio/security/advisories/new) (private disclosure)
2. Email **infra@cervio.app** with a short description, impact, and reproduction steps if available

We aim to acknowledge reports within a few business days and to ship a fix or mitigation as soon as practical.
